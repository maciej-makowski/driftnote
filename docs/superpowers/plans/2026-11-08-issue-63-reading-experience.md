# Issue 63 implementation plan: reading experience and the Newsreader serif

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Spec:** [`docs/superpowers/specs/2026-11-08-issue-63-reading-experience.md`](../specs/2026-11-08-issue-63-reading-experience.md). The spec carries the file-by-file detail and the font authoring recipe; this plan is the execution checklist. One PR, no parallel worktrees.

## Steps

- [ ] 1. Author the fonts once, outside the repo toolchain: install fonttools plus brotli in a scratch venv; instance the Google Fonts variable sources (roman and italic) at wght=400 and opsz=17; pyftsubset each static cut to the Google Fonts latin and latin-ext codepoints with `--flavor=woff2` and `--layout-features=*`; copy `OFL.txt` verbatim; record the measured byte counts of every file (latin pair and ext pair) and decide the latin-ext inclusion against the 90 KB worst-case budget.
- [ ] 2. Stage the files: the four WOFF2 files and `OFL.txt` under `src/driftnote/web/static/fonts/`; `style.css` (`--font-serif` in the second `:root` block, four `@font-face` rules with `font-display`, per-style `font-style`, per-subset `unicode-range`, `.entry-body`, the media grid, the back-link, video-radius, and quiet-button rules); `entry.html.j2` (back link, weekday h1, `.entry-body`, media grid, thumb alt and lazy attributes, quiet edit link, preload block); `base.html.j2` (the empty `head_extra` block); `entry_edit.html.j2` (unchanged this phase — the preload joins in phase 5); `search.html.j2` (input `aria-label`, heading-structured rows, em-dash kept); `routes_browse.py` (the static weekday filter and its registration).
- [ ] 3. Run the integration suite first, before any test edit, and compare against the pristine master run (bbf09ea: 240 passed, 2 skipped, 19 environmental errors, identical node ids). Patch only assertions that pin exact values this phase changes (confirmed for this phase: none).
- [ ] 4. Add the eight tests: weekday in the entry h1, the back link, thumb alt text and lazy grid markup with `preload="none"` on videos, the roman preload on entry, its absence on the edit page and calendar, the search input's `aria-label`, and the search row heading structure with the em-dash separator kept.
- [ ] 5. Add the one new contrast gate row the phase introduces (quiet button text on hover, fg on bg-hover) and confirm `scripts/check-contrast.py` exits 0.
- [ ] 6. Run the gates: `uv sync`; `uv run pytest -m "not live"` passes apart from the environmental testcontainers errors the pristine run reproduces with identical node ids; `uv run ruff check src tests`, `uv run ruff format --check src tests`, and `uv run mypy` are clean; every WOFF2 starts with the `wOF2` magic; `OFL.txt` is the licence text; `pyproject.toml` and `uv.lock` stay byte-identical.
- [ ] 7. Open the PR to `master`; CI (ruff, mypy, pytest, container smoke build) goes green; squash-merge. The font bytes ride the second batched deploy with phases 4 to 6 (Maciek-gated), and the measured byte counts update the design's 30 to 90 KB estimate.
